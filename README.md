# تطبيق دروسي القرآنية (Android)

مشروع Android Studio جاهز يحتوي على دروسك التسعة (ملفات HTML التفاعلية) داخل تطبيق أندرويد حقيقي، مع شاشة رئيسية لاختيار الدرس وعرضه داخل WebView.

## محتوى المشروع
- `app/src/main/assets/lessons/lesson-01.html` ... `lesson-09.html` — دروسك كما هي، بدون أي تعديل على المحتوى أو التصميم.
- `MainActivity` — قائمة الدروس التسعة.
- `LessonActivity` — يفتح الدرس المختار داخل WebView بملء الشاشة.
- الأذونات: تم تفعيل إذن الإنترنت لأن الدروس تستخدم:
  - خطوط Google Fonts
  - واجهة alquran.cloud لتلاوة الآيات
  - مقاطع يوتيوب مضمّنة (iframe)

## خطوات بناء ملف APK

### المتطلبات
1. تثبيت **Android Studio** (أحدث إصدار) من الموقع الرسمي: https://developer.android.com/studio
2. جهاز متصل بالإنترنت (لتنزيل Gradle ومكونات SDK تلقائيًا عند أول فتح للمشروع).

### الخطوات
1. افتح Android Studio واختر **Open** ثم حدّد مجلد المشروع `QuranLessonsApp`.
2. انتظر حتى ينتهي **Gradle Sync** تلقائيًا (يظهر شريط تقدم أسفل النافذة). إن طلب منك Android Studio "Install missing SDK" أو تنزيل نسخة Gradle، اضغط **Accept/OK**.
3. من القائمة العلوية اختر: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. بعد اكتمال البناء ستظهر رسالة صغيرة أسفل الشاشة تحتوي رابط **locate** — اضغط عليه لفتح مجلد ملف الـ APK.
   - المسار عادة: `app/build/outputs/apk/debug/app-debug.apk`
5. انسخ هذا الملف إلى هاتفك الأندرويد وثبّته (فعّل خيار "تثبيت من مصادر غير معروفة" إذا طُلب منك ذلك).

### لتوليد نسخة موقّعة (Release) لرفعها على متجر أو مشاركتها بشكل نهائي
1. من القائمة: **Build → Generate Signed Bundle / APK**.
2. اختر **APK**، ثم أنشئ مفتاح توقيع جديد (Key store) عبر **Create new...** واملأ البيانات المطلوبة واحفظ كلمة المرور في مكان آمن.
3. اختر **release** كنوع البناء وأكمل الخطوات — سينتج ملف APK موقّع جاهز للتوزيع في:
   `app/release/app-release.apk`

## تخصيص لاحق (اختياري)
- **الأيقونة**: تم توليد أيقونة بسيطة بألوان الدروس (أخضر زمردي/ذهبي). لاستبدالها بأيقونة خاصة بك، استخدم داخل Android Studio: **File → New → Image Asset** واستبدل ملفات `ic_launcher` في مجلدات `mipmap-*`.
- **اسم التطبيق**: عدّل القيمة في `app/src/main/res/values/strings.xml`.
- **إضافة درس جديد**: ضع ملف الـ HTML داخل `app/src/main/assets/lessons/`، ثم أضف سطرًا جديدًا في `MainActivity.java` داخل الدالة `buildLessonList()`.
- **العمل بدون إنترنت بالكامل**: بعض العناصر (الخطوط، تلاوة القرآن، فيديو يوتيوب) تُحمَّل من الإنترنت حاليًا. لجعل التطبيق يعمل بلا إنترنت تمامًا يلزم تنزيل هذه الملفات (خطوط، ملفات صوتية) ووضعها محليًا داخل `assets` وتعديل روابطها في ملفات HTML — أخبرني إن رغبت بذلك وسأجهزه لك.

## ملاحظة
لم يكن ممكنًا توليد ملف APK نهائي من هذه المحادثة مباشرة لعدم توفر أدوات بناء أندرويد (Android SDK / Gradle) واتصال إنترنت في بيئة التنفيذ الحالية. هذا المشروع جاهز 100% للبناء الفوري بمجرد فتحه في Android Studio على جهازك خلال دقائق.

## بديل: بناء APK تلقائيًا عبر GitHub (بدون تثبيت أي برنامج على جهازك)

يحتوي المشروع على ملف `.github/workflows/build.yml` يجعل GitHub يبني ملف الـ APK تلقائيًا مجانًا في كل مرة ترفع فيها الملفات.

### الخطوات
1. أنشئ حسابًا مجانيًا على https://github.com إن لم يكن لديك.
2. أنشئ مستودعًا جديدًا (New repository) باسم مثل `QuranLessonsApp`.
3. ارفع محتويات هذا المجلد بالكامل إلى المستودع (بما فيها مجلد `.github` — تأكد أن ملفات إعدادات المخفية تُرفع، فهي جزء أساسي من الآلية).
4. بعد الرفع، افتح تبويب **Actions** أعلى صفحة المستودع — ستجد عملية بناء (Build APK) تعمل تلقائيًا، انتظر حتى تظهر علامة ✔ خضراء (دقيقة إلى دقيقتين).
5. اضغط على عملية البناء المكتملة، ثم في أسفل الصفحة ستجد ملفًا باسم **app-debug-apk** تحت قسم "Artifacts" — نزّله (سيكون بصيغة zip يحتوي على ملف app-debug.apk).
6. انقل الـ APK إلى هاتفك وثبّته (فعّل "تثبيت من مصادر غير معروفة" إذا طُلب منك ذلك).

بهذه الطريقة تحصل على ملف APK حقيقي جاهز للتثبيت دون تثبيت Android Studio أو أي أداة على جهازك.
